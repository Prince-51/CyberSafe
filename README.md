🛡️ CyberSafe

**Your Digital Safety Companion**

CyberSafe is a beginner-friendly cybersecurity awareness website that helps users identify online threats, learn safe digital practices, and respond to common scams.

--> ✨ Features

   * 🔎 URL Safety Checker
   * 🔐 Password Strength Checker
   * 🎣 Phishing Awareness
   * 🚨 Scam Awareness
   * 📰 Cyber Incident Archive
   * 🆘 Scam Emergency Guide
   * 📚 Cybersecurity Learning
   * 🌙 Dark & Light Mode
   * 📱 Responsive Design
